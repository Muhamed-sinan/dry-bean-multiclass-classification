# Dry Bean Multiclass Classification using Machine Learning

## Project Overview
This project classifies dry bean varieties using machine learning algorithms and numerical features.

## Dataset
Target: `Class`

Features include Area, Perimeter, MajorAxisLength, MinorAxisLength, Eccentricity, ConvexArea, Solidity, Compactness and ShapeFactor features.

## Algorithms Used
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier
4. K-Nearest Neighbors (KNN)
5. Gaussian Naive Bayes
6. Support Vector Machine (SVM)
7. Gradient Boosting Classifier

## Workflow
- Data loading and exploration
- Missing-value and duplicate checks
- Feature and target separation
- Label encoding
- Train-test split
- Feature scaling
- Model training and evaluation
- Accuracy comparison and confusion matrices

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook
